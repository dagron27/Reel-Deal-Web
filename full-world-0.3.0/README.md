# Reel-Deal — full-world archive (`0.3.0`)

A frozen snapshot of Reel-Deal as it stood at git tag `0.3.0`: a 12-region
overworld (Town, Pond, Lake, Swamp, River, Ocean, Mangrove Bay, Sandy Shore,
Fishing Village, Fishing Lodge, Forest, Mountains) with a world-map travel
screen and a pet-fish mechanic, before the scope reduction that collapsed the
game down to a single composite Lake.

This build won't be updated — it exists purely as a playable reference for
the pre-reduction version. The current, actively developed build is at the
site root: <https://dagron27.github.io/Reel-Deal-Web/>.

See the source repo's `Cabinet-Shared/lessons/reel-deal/2026-09-scope-reduction.md`
for the full narrative of what changed and why.
